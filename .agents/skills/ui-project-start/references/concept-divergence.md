# Concept Divergence

## Dimensions that count as meaningful differences

- information architecture
- navigation model
- spatial composition
- information density
- disclosure model
- primary interaction
- persistent, contextual, and transient information
- feedback model
- visual metaphor
- content priority

Every pair of directions must differ meaningfully on at least four dimensions.

## Differences that do not count

- changing the number of columns in the same card grid
- changing sidebar width or position
- light theme versus dark theme
- radius, shadow, or gradient changes
- swapping fonts or icons
- mirroring the same structure left to right

## Direction names

Name directions after how they work.

Good examples: `Comparison Workbench`, `Guided Decision Flow`, `Context-Reactive HUD`, `Map-First Exploration`.

Weak examples: `Blue`, `Modern`, `Dark`, `Minimal`, `Premium`.

## Design signatures

Use no more than three signatures per direction:

- one structural signature
- one interaction signature
- one visual signature when necessary

Keep most patterns familiar and predictable. Make only the small set of decisions that create product identity distinctive.

## Regeneration

When directions are too similar, discard one and fundamentally change at least one of:

- core object and screen center
- hierarchical navigation ↔ task-oriented navigation
- same-screen comparison ↔ staged decision
- persistent information ↔ contextual information
- separate detail ↔ inline disclosure
- real-time reaction ↔ review-and-confirm time model
