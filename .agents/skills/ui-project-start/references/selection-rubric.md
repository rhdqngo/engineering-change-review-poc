# Direction Selection Rubric

Score each item from 0 to 4.

| Criterion | Weight | Core question |
| --- | ---: | --- |
| Core-task fit | 22 | Does it support the most important action quickly and accurately? |
| Content and state adaptability | 13 | Does priority hold under real/extreme content and failure states? |
| Structural distinctiveness | 12 | Does the direction arise from the product problem? |
| Perceptual stability | 10 | Are alignment, text fit, icons, rhythm, and state transitions stable in rendered UI? |
| Narrative restraint | 8 | Does prose support rather than replace objects, state, and actions? |
| Input and platform fit | 8 | Does it fit primary screens, inputs, and time pressure? |
| Accessibility and clarity | 8 | Is information legible and redundantly signaled instead of buried in decoration? |
| Scalability and consistency | 8 | Does it define a reusable grammar and role invariants? |
| Trust and recovery | 7 | Are outcomes, errors, recovery, and necessary rationale clear? |
| Implementation risk | 4 | Is technical cost proportional to product value? |

## Evaluating perceptual stability

- Are repeated alignment lines and heights stable for the same role?
- Does long localization and the production/fallback font avoid accidental wrapping?
- Are icon-label composition and visual weight stable?
- Do loading, badges, validation, and errors avoid unnecessary layout movement?

## Evaluating narrative restraint

- Does the first region show real objects, state, and actions?
- Do page subtitles and helper paragraphs avoid repeating visible headings and controls?
- Does persistent copy serve identification, state, constraint, consequence, recovery, or rationale?
- Is first-use guidance removed from recurring workflows after it is no longer needed?
- Does the empty state avoid becoming a feature-marketing page?

## Disqualifying conditions

- the core-task path is unclear
- key states cannot fit within the structure
- the primary input method cannot operate it
- it harms competitive fairness or obscures consequences in a high-stakes action
- it effectively preserves an unapproved existing visual structure
- it is not structurally distinct from another direction
- a primary control wraps accidentally or repeated alignment collapses in a supported viewport
- persistent prose appears before real objects, state, and actions and merely narrates structure

Scores do not replace judgment. The recommendation must explain why the winner was selected, which risks are accepted, and which elements from rejected directions must not be imported.
