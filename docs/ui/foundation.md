# UI Foundation

state: provisional  
version: 0.1  
updated: 2026-08-20

## Direction

Use a restrained engineering docket: dark mission header, warm paper surface, thin rules, compact monospace identifiers, and a single amber environment strip. The layout communicates control and traceability without imitating a generic dashboard.

## Information architecture

1. Environment/result provenance.
2. Frozen case identity and change statement.
3. Candidate seal and arm summary.
4. Fixed six-row candidate docket.
5. Selected evidence and fail-closed checks.

## Roles

- Candidate identifier: monospace, compact, never truncated without a full accessible value.
- Disposition: terse uppercase token; color reinforces but never carries meaning alone.
- Evidence: exact source text in a dark code surface.
- Audit rejection: rust text under “Fail-closed record,” never mixed with admitted advice.

## Responsive behavior

At widths below 760 px, header and summary collapse vertically. The candidate docket remains a horizontally scrollable comparison object; the evidence desk follows it in document order. It does not mechanically stack table cells into ambiguous cards.

## Governance

This Foundation is provisional and applies only to the PoC Demo UI. It is not approved reusable precedent.
