# Security Policy

## Supported version

Security fixes are applied to the current `main` branch. Historical experiment tags are immutable research artifacts and are not patched in place.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, private cloud identifiers, or user data.

Include the affected commit, reproduction conditions, impact, and the smallest proof needed to confirm the issue. Do not test against cloud resources or submit billable model requests without explicit authorization.

This repository is a proof of concept, not flight-qualified or production safety software. No support or response-time SLA is provided.
